# jevm

System One decisions for your shell, your agents, and your Go code — one binary (`jev`), three ways in: verb-first CLI, MCP server (`jev serve`, official [modelcontextprotocol/go-sdk](https://github.com/modelcontextprotocol/go-sdk)), and a thin typed Go SDK (this repo's root package). Wraps OpenCode Zen's System One endpoint (`POST https://opencode.ai/zen/v1/systemone`, model `jev-1.13`).

Status: **design phase** — see [docs/design.md](docs/design.md). No code yet.
